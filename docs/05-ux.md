# UX specification: MVA Transparent Prioritizer

## User and context

The first surfaces are `cli` and `library`. The operator uses them on macOS during a time-bounded research workflow. The operator has technical fluency and needs short status output with deep local evidence on demand. Plain text must remain usable through a screen reader and redirected logs.

## Information architecture

The operator works with five nouns: environment, manifest, run, dossier, and safe projection. Each command maps to one noun and one state transition. Detailed private output never appears in terminal output.

## Flow specification

Three directions were considered. A single black-box command is fast and hard to audit. A loose toolbox exposes detail and makes replay fragile. The chosen direction is a staged CLI with immutable receipts and one content-free status summary.

The happy path runs environment verification, synthetic acceptance, private analysis, receipt verification, and local review. A failed preflight names one content-free error code and the local log label. Recovery creates a fresh run ID after the fault is corrected. Source deletion is outside the CLI and requires a separate reviewed manifest.

The interface covers `ready`, `running`, `incomplete`, `failed_closed`, `empty_result`, `review_ready`, `stale_receipt`, and `privacy_blocked`. A stale or failed receipt disables projection and review-ready status.

## Interaction details

Commands state what they will read and write before execution. Success output contains the run state, aggregate stage count, and private artifact label without an absolute path. Errors use stable codes. The CLI never prints a sample name, HPO identifier, variant, coordinate, genotype, phenotype phrase, or dossier excerpt. Every state has a word and exit code, so color is optional.

## Usability evidence

Synthetic acceptance will test the main journey, a tampered-reference failure, an empty result, and a privacy block. Snapshot tests cover narrow and wide terminal widths, redirected output, and stable text order. The first release will not add a visual interface before this flow passes independent review.
